# 概述

MachTable（马赫表格）是面向复杂 B 端业务的 TypeScript 数据表格。框架无关 Core 采用 DOM 行列双虚拟化，保持零运行时依赖；Vue/React 提供相同领域 API 和各自自然的组件接入方式。

## 场景与默认值

| 场景 | 接入方式 |
| --- | --- |
| 日常主列表 | Vue/React 直接使用 `MachTable`，省略 `preset` 即为 `list` |
| 同页多张小明细 | 每张传自己的列和数据，加 `preset="detail"`；纯文字表头、默认只读、不分页、有界内容高度 |
| 远程查询与批量编辑 | 复用 `/workflows`，按需组合已有控制器和工具栏 |
| 树、分组、分析与导入 | 使用现有数据模型或可选子入口，遵守对应资源上限与数据范围 |

主列表默认显示序号和内置分页，数值与普通内容默认居中；单表显式属性优先。只有项目存在统一差异时才增加应用配置，不要求每个页面重复关闭工具或二次包装表格。完整规则见[场景与配置](/guide/configuration)。

## 当前能力

| 方向 | 能力与边界 |
| --- | --- |
| 渲染与规模 | 行池复用、列窗口、变高行 Fenwick 索引、rAF 合帧、增量事务及有界诊断；窗口限制可见 DOM，模型计算和业务 renderer 成本另行测量 |
| 列布局 | 有界内容测宽、按比例铺满、完整表头最小宽度、独立拖宽、左右固定、多级表头和动态列 |
| 数据 | 本地数据、远程分页、连续加载、随机块、树/懒加载及可选服务端分组 Store；每表选择一个数据所有者 |
| 编辑 | 单元格/整行事务、同步异步校验、粘贴/填充、脏数据、撤销重做、部分保存与冲突审阅 |
| 选择与分析 | 单/多选、跨页选择规则、范围/多范围、分组聚合及可选 Pivot、公式和图表；远程分析不冒充全量结果 |
| 状态与治理 | 身份隔离偏好、命名视图、字段迁移、动态 schema、类型化 IO、公开 API/消费端/兼容/长稳门禁 |

服务端权限、原子 CAS、全量统计、跨层快照及文件任务由真实后端提供。字典插件和 HTTP 客户端由项目组合，表格只接收普通列、选项与 formatter，不依赖对应服务包。完整能力与限制见[当前路线](/advanced/roadmap)。

## 技术与产品边界

- DOM 路线服务于复杂业务控件、编辑与键盘操作。完整多工作表、自由文档布局和多人协作应按电子表格产品需求独立评估。
- 同一页面的明细表分别持有数据和状态；共用主题或列定义不代表共用选择、编辑或滚动状态。
- 超大数据优先按需请求，不为逻辑行数预先分配完整数组。目标设备上的性能以实际业务列和测量报告为准。
- 真实消费者体积与原始发布包解压大小分别检查，当前字节预算见[性能指南](/advanced/performance#发布体积预算)。

竞品调研和 VTable/AG Grid 对照保留为[历史分析](/advanced/competitive-analysis)，旧版功能、依赖数和体积不作为当前结论。跨产品性能须固定版本、数据、任务和硬件进行比较。

## 包结构

| 包 | 说明 |
| --- | --- |
| `@agile-team/mach-table` | 零运行时依赖 Core、原生用法和主题 CSS |
| `@agile-team/mach-table-vue` | Vue 组件、配置、同步/异步接入与可选工作流；peer 为 Vue ≥3.2 |
| `@agile-team/mach-table-react` | React 组件、Provider、生命周期与可选工作流；peer 为 React/ReactDOM ≥18 |
| `@agile-team/mach-table-xlsx` | 按需工作簿桥接，具体文件引擎由宿主选择 |

四个发布包通过 Changesets fixed 版本组同步发版；按需入口保持独立消费边界。Vue/React 项目只安装自己的适配包，Excel 页面按需增加 XLSX 扩展。

## 兼容、验证与授权

- 实际布局回归覆盖报告记录的 Chromium、Firefox、WebKit。构建目标及 `ResizeObserver`、`PointerEvent` 等能力要求，不等于旧版 Chrome、Firefox 或 Safari 已验收；企业指定浏览器需按目标版本复测。
- 仓库开发与文档构建使用 Node.js ≥22.22.2、pnpm 11.8.0；固定框架版本及生命周期检查见[质量门禁](/advanced/quality-gates#固定框架兼容矩阵)。
- SSR 可安全导入公共入口，DOM 实例在客户端挂载后创建；必要时通过公开布局 API 刷新容器尺寸。
- 真人读屏、缩放和输入法验收见[人工清单](/advanced/accessibility#尚需真实读屏软件验收)，正式版判断见 [1.0 就绪评估](/advanced/release-readiness)。
- MachTable 从 0.9.1 起采用 Source-Available 授权，查看源码不代表获得使用权，详见[许可证与授权](/guide/licensing)。
