# 国际化 i18n

内置中文文案，`locale` 覆盖任意键。弹层（过滤面板/列菜单/右键菜单/状态栏/加载条）文案全部可配。

## 英文预设

```ts
import { LOCALE_EN } from "@agile-team/mach-table";

createGrid(host, { locale: LOCALE_EN, ... });
```

## 自定义（部分覆盖）

```ts
createGrid(host, {
  locale: {
    apply: "OK",
    reset: "Clear",
    totalRowsLabel: "{n} 条",   // {n} 占位符
    menuPaste: "贴入"
  }
});
```

## 全量键与默认值

```ts
import { DEFAULT_LOCALE } from "@agile-team/mach-table";
```

| 键 | 默认（中文） | 场景 |
| --- | --- | --- |
| `matchContains` … `matchInRange` | 包含/不包含/等于/不等于/开头是/结尾是/为空/不为空/小于/小于等于/大于/大于等于/在范围内 | 过滤条件下拉 |
| `apply` / `reset` | 应用 / 重置 | 过滤面板按钮 |
| `search` | 搜索... | set 过滤搜索框 |
| `emptySetLabel` | (空) | set 过滤空值项 |
| `selectedCount` | 已选 {n} 项 | set 过滤摘要 tag |
| `sortAsc` / `sortDesc` / `clearSort` | 升序 / 降序 / 取消排序 | 列菜单 |
| `pinLeft` / `pinRight` / `clearPin` | 固定左侧 / 固定右侧 / 取消固定 | 列菜单 |
| `autoSize` / `hideColumn` | 自适应列宽 / 隐藏此列 | 列菜单 |
| `columnVisibility` / `resetAll` / `autoSizeAll` / `columnSettings` | 列显示 / 重置全部 / 全部自适应 / 列设置 | 列面板 |
| `menuCopy` / `menuPaste` / `menuClearContents` | 复制 / 粘贴 / 清除内容 | 右键菜单 |
| `loading` | 加载中... | 无限滚动指示条 |
| `totalLabel` / `totalRowsLabel` | 合计 / 共 {n} 行 | 合计行 / 状态栏 |
| `statusSelected` | 已选 {n} 行 | 状态栏 |
| `statusSum` / `statusAvg` / `statusCount` | 和 {n} / 均 {n} / 计 {n} | 状态栏范围聚合 |
| `emptyRows` / `emptyRowsHint` | 暂无数据 / 没有可显示的行 | 内置空数据插画文案 |
| `paginationTotal` / `paginationPage` / `perPage` | 共 {n} 条 / 第 {a} / {b} 页 / {n} 条/页 | 分页条 |
| `pageFirst` / `pagePrev` / `pageNext` / `pageLast` | 首页 / 上一页 / 下一页 / 末页 | 分页按钮提示 |

## 与应用 i18n 框架联动

```ts
import { i18n } from "@/locales";

const gridLocale = computed(() =>
  i18n.global.locale.value === "en" ? LOCALE_EN : {}
);

// Vue
<RobotGrid :locale="gridLocale" ... />

// 运行时切换（原生）
watch(locale, (v) => api.updateOptions({ locale: v === "en" ? LOCALE_EN : {} }));
```

## 工具

```ts
import { formatText, matchLocaleKey } from "@agile-team/mach-table";
formatText("已选 {n} 项", 3);       // "已选 3 项"
matchLocaleKey("greaterThanOrEqual") // "matchGreaterThanOrEqual"
```

## 注意

- 表头文本、单元格内容、合计行文案（summaryMethod 返回值）由业务数据决定，不经过 locale
- 日期格式化默认跟随浏览器 `toLocaleDateString()`；统一格式请在列 `valueFormatter` 处理
