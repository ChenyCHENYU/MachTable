# 0.19 能力边界与路线图

MachTable 0.19 面向复杂中后台、工业台账、订单/工单和运营工作台。0.10—0.19 已形成“接入、查询、编辑、个性化、治理、诊断、远程大数据”的核心闭环，但仍处于 0.x：本次不冻结 1.0 API，也不把 Pivot、图表、公式等低频重能力塞进默认包。

竞品证据、评分矩阵和实测方法见[竞品调研](/advanced/competitive-analysis)与 [AG Grid 源码审计](/advanced/ag-grid-source-study)。

## 已交付里程碑

| 版本 | 核心目标 | 验收结果 |
| --- | --- | --- |
| 0.10 | 配置 V2、命名预设、响应式 scoped defaults、自动 fit、Vue 原生插槽 | 配置来源可解释，应用/路由/表格分层覆盖 |
| 0.11 | 远程分页、请求取消、加载/空/错状态、跨页选择 | 包含竞态保护、重试与 query-wide 选择规则 |
| 0.12 | 业务列、字典缓存、EP 编辑器、保存闭环 | TTL/LRU/批量字典、部分保存、回滚和可选 EP 桥接 |
| 0.13 | 列工作台、权限动作、XLSX、懒加载树、主从详情 | XLSX 独立包；树加载具备中止、去重、失败重试 |
| 0.14 | 控制器、工具栏、React 工作流、完整状态、手动查询 | 基础/工作流/可选 UI 分入口并独立体积门禁 |
| 0.15 | 显式列宽拖动、取消回滚、fit/flex 恢复、宽度 API | jsdom 状态机与三浏览器真实拖动恢复门禁 |
| 0.16 | API 治理设计 | 能力并入 0.18：元数据驱动 Option 边界、Feature manifest |
| 0.17 | 复杂业务工作区 | 能力并入 0.18：高级过滤、命名视图、保存失败/冲突协议 |
| 0.18 | 迁移、渲染与性能证据 | GridState v2、原地 renderer refresh、滚动性能快照与 100k×100 门禁 |
| 0.19 | 性能内核与 API 治理 | 随机块 LRU、Worker、增量行高/二分列索引、批更新、领域 API 与 API snapshot |
| 1.0 | API 冻结、迁移工具、无障碍/安全/视觉回归 | 尚未冻结；由真实项目证据驱动 |

## 明确边界

| 场景 | 当前选择 |
| --- | --- |
| 服务端随机块访问、分组/聚合下推 | 尚无完整 SSRM；现有远程分页和顺序无限模式不冒充 SSRM |
| Pivot / 透视分析 / 图表联动 | 不进入 Core；优先服务端预聚合或按真实项目独立立项 |
| 公式引擎与协同编辑 | 未实现；需要独立安全、计算和冲突模型 |
| Canvas 超密集只读分析 | DOM 虚拟化优先，保留业务组件和可访问性；此类场景应重新选型 |
| XLSX 引擎 | 宿主按需安装并动态注入，不锁定或捆绑第三方工作簿引擎 |
| 树形跨层拖拽 | 不自动改变父子关系；业务显式提交并由服务端校验 |

## 1.0 前退出条件

1. 公共 API 兼容清单、弃用周期和 `RobotGrid` 迁移工具完成。
2. GridState、错误码、配置和列状态具备跨未来版本的 fixture 迁移测试。
3. 至少两个真实项目完成查询、批量编辑、冲突处理、懒加载树、列工作台和 XLSX UAT。
4. 公开可复现性能结果、内存泄漏、真机读屏、CSP/注入矩阵持续通过。
5. 浅/深主题、三档密度、编辑/错误/空状态建立视觉回归。
6. 发布候选包完成安装、回滚、授权元数据、tarball 和多包版本一致性演练。

## 企业级判断

在“复杂业务数据浏览与录入组件”的目标范围内，0.19 已达到企业项目试点标准：API 输入/结构治理、可迁移状态、冲突保存、随机块缓存、Worker 边界、资源销毁、安全默认值和自动化门禁均有实现与测试。它仍不等同于 AG Grid Enterprise 的 SSRM/Pivot/图表生态，也不应在没有真实 UAT、读屏和发布回滚证据时宣称 1.0 成熟。
