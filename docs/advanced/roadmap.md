# 0.24 能力边界与后续路线

MachTable 0.24 面向复杂中后台、工业台账、订单/工单和运营工作台，仍处于 0.x 产品验证阶段。本版本完成公共 API、框架入口、配置与持久化的集中治理，为真实项目试点提供清晰基线。

## 已完成

| 方向 | 0.24 结果 |
| --- | --- |
| 公共 API | 12 个冻结领域 + 7 个根级横切能力，删除平面重复入口和内部实现导出 |
| 框架一致性 | Vue/React 统一 `MachTable`、`useMachTable`、`bindings` 与子入口结构 |
| 配置中心 | 类型和运行时都阻止实例数据/身份进入 defaults/preset，默认严格失败 |
| 状态 | 单一 `persistence` 配置统一完整状态与仅列偏好；GridState v2 单一契约 |
| 扩展隔离 | 移除进程级可变组件 registry；内置组件不可变，业务按应用/实例注入 |
| 性能 | 双虚拟化、增量事务、批处理、随机块调度、Worker 边界与诊断继续受门禁 |
| 工程质量 | API/复杂度/依赖/覆盖率/包体/exports/示例/文档/发布产物统一验证 |

## 当前适用范围

推荐进入真实项目试点的场景：

- 本地与服务端分页 CRUD 列表。
- 单元格/整行编辑、批量保存、部分失败与版本冲突。
- 树、懒加载树、分组聚合与主从详情。
- 列工作台、列宽记忆、完整工作区恢复和命名视图。
- 顺序无限滚动与百万级随机块长列表。
- Vue 3 主项目和 React 18+ 项目。

0.24 不宣称等同 AG Grid Enterprise 的完整 SSRM、Pivot、公式和图表生态，也不构成 1.0 API 冻结。

## 真实项目验证期

下一阶段优先收集证据，而不是继续堆功能：

1. 至少两个真实 B 端项目的接入时间、重复封装量和 API 摩擦点。
2. CRUD、远程分页、整行编辑、树与大数据场景的 UAT。
3. 目标设备性能 trace、内存、连续滚动和路由反复挂载数据。
4. 键盘、读屏、颜色对比和企业设计系统集成反馈。
5. 0.24 minor 升级演练、npm 回滚和授权流程验证。

## 后续优先级

### P0：成熟度与易用性

- 示例站/Playground 与可复制业务模板。
- 配置和列 schema 的开发期诊断面板。
- 完整视觉回归、无障碍矩阵和真实 bundler 体积基线。
- 文档示例编译与 API 链接自动校验。

### P1：高频复杂业务

- 高级筛选构建器 UI。
- 批量修改审阅面板。
- 服务端分组/聚合行模型协议与缓存一致性。
- 更完整的打印分页和大表导出任务协议。

### P2：按证据独立立项

- Pivot、公式、图表、Excel 大范围选区。
- 服务端增量订阅与层级 Store。
- 商业 Pro 扩展及授权交付体系。

这些能力优先作为独立 Feature/包设计，避免污染 Core 和普通页面体积。

## 1.0 条件

至少满足以下条件再讨论 1.0：

- 公共 API 经真实项目验证并完成一次可复现升级演练。
- 状态、错误码、事件和框架入口冻结。
- 性能、无障碍、安全、视觉回归和发布回滚门禁成熟。
- 官方示例、企业接入手册和迁移工具与实现同步。
- 授权申请、交付与版本支持边界可执行。

1.0 的目标是可信的长期契约，不是版本号营销。
