# 0.14 能力边界与路线图

MachTable 0.14 面向复杂中后台、工业台账、订单/工单和运营工作台。0.10—0.14 的核心路线已形成闭环，但源码仍处于 0.x 打磨期：本次不冻结 1.0 API，也不把 Pivot、图表、公式等低频重能力塞进默认包。

竞品证据、评分矩阵和实测方法见[竞品调研](/advanced/competitive-analysis)与 [AG Grid 源码审计](/advanced/ag-grid-source-study)。这里记录已经落地的能力与仍然明确保留的边界。

## 版本里程碑

| 版本 | 核心目标 | 0.14 源码验收结果 |
| --- | --- | --- |
| 0.10 | 配置系统 V2、命名预设、响应式 scoped defaults、自动 fit、Vue 原生插槽 | 已完成；配置来源可解释，应用/路由/表格分层覆盖 |
| 0.11 | `useMachTableQuery`、远程分页、请求取消、加载/空/错状态、跨页选择 | 已完成；包含竞态保护、重试与 query-wide 选择规则 |
| 0.12 | 业务列类型、字典缓存、Element Plus 编辑器、完整编辑保存闭环 | 已完成；包含 TTL/LRU/批量字典、部分保存、回滚与可选 EP 桥接 |
| 0.13 | 列工作台、权限动作、XLSX 可选扩展、树表懒加载、主从详情 | 已完成；XLSX 不进入 Core，懒加载具备中止/去重/失败重试 |
| 0.14 | 组合控制器、标准工具栏、React 工作流对齐、完整状态自动持久化、错误态、手动查询、自动高度 | 已完成；基础适配器/工作流/可选 UI 分入口并独立执行体积门禁 |
| 1.0 | API 冻结、迁移工具、性能/无障碍/安全/视觉回归门禁 | 未开始冻结；继续由真实项目 UAT 驱动 |

早期提交曾把 0.11/0.12 能力合并到 0.10 源码中，造成“功能已存在但版本路线未兑现”的阅读混乱。0.13 起按能力矩阵统一版本、Changelog、文档和测试口径，不再用文档计划替代可运行实现。

## 0.14 已具备

| 维度 | 能力 |
| --- | --- |
| 大数据 | 行/列双虚拟化、变高行定位、10 万行 × 100 列预算、高频异步事务合批 |
| 数据请求 | 受控服务端分页、取消/竞态保护、加载/空/错状态、顺序无限数据源、跨页与全查询选择 |
| 数据模型 | 客户端排序/过滤/分页、树/懒加载树、分组聚合、主从明细、固定行 |
| 编辑 | 单元格与原子整行编辑、同步/异步校验、撤销重做、脏数据、部分保存确认、回滚与离页保护 |
| 业务建模 | 语义列类型、TTL/LRU/批量字典缓存、Vue/Element Plus 编辑器桥接、Schema/字段路径助手 |
| 操作与权限 | 任意动作、查看/编辑/删除预设、菜单/抽屉/全展开、统一权限/确认/错误策略 |
| 个性化 | 可搜索列工作台、显隐/固定/排序/列宽、版本化列状态与完整 `GridState` |
| 导入导出 | 安全 CSV、打印、水印；XLSX 为独立动态扩展，不增加默认包体 |
| DX | Vue 单包安装、全局/异步注册、专用配置文件、命名 preset、原生插槽；React 官方适配 |
| 治理 | 稳定错误码、诊断快照、运行时配置校验、资源销毁、复杂度/类型/覆盖率/体积/消费端门禁 |

## 明确边界

| 场景 | 当前选择 |
| --- | --- |
| 服务端随机块访问、分组/聚合下推 | 尚无完整 SSRM；现有远程分页和无限模式不冒充 SSRM |
| Pivot / 透视分析 / 图表联动 | 未进入 Core；优先服务端预聚合或按真实项目独立立项 |
| 公式引擎与协同编辑 | 未实现；需要独立安全模型、计算模型和冲突协议 |
| Canvas 超密集只读分析 | DOM 虚拟化优先，保留业务组件和可访问性；此类场景应重新选型 |
| XLSX 引擎 | 由宿主按需安装并动态注入，MachTable 不锁定或捆绑第三方工作簿引擎 |
| 树形跨层拖拽 | 当前不自动改变父子关系；业务必须显式提交并由服务端校验 |

## 1.0 前退出条件

1. 公共 API 兼容清单、弃用周期和 `RobotGrid` 迁移工具完成。
2. `GridState`、错误码、配置文件和列状态具备跨版本迁移测试。
3. 真实业务项目完成远程查询、批量编辑、懒加载树、列工作台和 XLSX 的 UAT。
4. 公开可复现的性能基准、内存泄漏、无障碍读屏、CSP/注入安全矩阵持续通过。
5. 浅色/深色、三档密度、编辑/错误/空状态建立像素级视觉回归。
6. 发布候选包完成安装、回滚、授权元数据、tarball 内容和多包版本一致性演练。

## 企业级判断

在“复杂业务数据录入与浏览组件”的目标范围内，0.14 已达到企业项目试点标准：类型、错误隔离、可恢复状态、资源销毁、安全默认值和自动化门禁均有实现与测试。它仍不等同于 AG Grid Enterprise 的全部分析功能与生态成熟度；大规模推广前必须由真实项目完成 UAT、性能画像、无障碍抽查和回滚演练。
