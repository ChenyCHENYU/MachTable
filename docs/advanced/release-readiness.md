1.0 承诺的是已声明支持范围内的兼容与维护责任。功能数量、通过用例总数或某次性能结果都不能单独证明成熟度。新增能力只在存在实际业务需求且边界明确时继续扩展。

## 当前结论

本次复核已关闭实际复现的编辑几何、虚拟释放、强制刷新、清理重入和 Vue 生命周期问题，最终 0.42.1 的本地工程门禁与长稳通过。工程基础具备进入 **1.0 候选评审**的条件；正式 1.0 的支持范围与人工待验项处理方式仍需维护者评审，不能把自动化通过扩展为全部真实业务和辅助技术认证。

真实接口权限、并发版本、聚合/导出范围及业务升级回退仍需业务 UAT；辅助技术目前暂无真人验收环境，继续记录待人工，不宣称相应兼容认证。隔离状态往返验证不等同于真实系统升级演练。GitHub Actions 还需恢复执行后对最终提交复跑，本地通过不代替远端通过。

发布决定以维护者对上述范围和证据的评审为准。本文不通过增加新框架、重写渲染引擎或扩展全部竞品能力来设置额外门槛。

## WebKit 编辑边界的修复

在 Playwright WebKit 中，**超宽合并单元格保持原生输入框焦点、横向滚动后再实际调整合并宽度**，浏览器会把祖先的横向滚动位置拉回起点。固定复现使用 110 个 80px 列合并，滚动到 8,005px，再将其中一列从 80px 调为 81px；实际调宽后 **20/20** 复现。脱离 MachTable 的纯 HTML 对照也能复现，脚本 setter 记录没有写回 0。

此前候选消除了虚拟窗口重排中不必要的 `8800 → 80 → 8800px` 变化，但没有覆盖实际调宽。本轮保留逻辑单元格宽度，将编辑输入限制到当前分区可见范围；横滚只调整输入外壳的位置。容器扩到 9000px 后，列虽不再超宽，左侧仍可能部分滚出，因此同时处理部分可见状态。

三浏览器隔离对照覆盖普通与合并超宽列、单格与整行编辑、普通与复合输入、实际调宽、容器变化、反向选区及自定义 fixed 后代定位。完全离开跨度时统一释放编辑器并移除隐藏 DOM，整行草稿返回时恢复。最终统一产物的执行记录与门禁单独列出，不将 Playwright WebKit 的有限结果扩大为全部 Safari 版本认证。

本轮未加入循环补写滚动位置、自动提交部分可见编辑或隐式转移焦点。普通浏览态不新增 DOM 测量、观察器或定时器；整行定位只遍历已挂载的编辑器，普通列用既有 CSS 几何预筛选。旧失败诊断保留在 `core/span-repro/diagnosis/`，后续对照在工作区 `output/machtable-editor-geometry-20261115/`。
